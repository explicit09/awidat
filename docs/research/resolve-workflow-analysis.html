Montage Resolve Workflow Research

Separate research pass for the nine DaVinci Resolve tutorial videos supplied on 2026-05-16. This report is intentionally separate from the earlier editorial grammar work. It focuses on what professional editors do in tools like Resolve and Premiere, what Montage already covers, and where Montage should improve before implementation planning.

Companion JSON: docs/research/resolve-workflow-analysis.json
Method: YouTube metadata and available English captions were collected with yt-dlp. Full transcripts are not embedded here; this artifact keeps structured notes and implementation-oriented findings.

Executive Read

North Star

Montage should be an agent editor that produces professional-quality edits for people who are not professional editors. The user asks for an outcome; the agent inspects, decides, edits, reviews, and delivers.

What Resolve Makes Obvious

Resolve is useful as a map of professional editing work: organize media, assemble the cut, composite, grade, mix, and deliver. Montage does not need to look like Resolve, but it must cover the work.

What Montage Already Does Well

Montage already has an agent-native EDL path, semantic cut intent, J/L split edit metadata, transitions, titles, captions, color controls, audio controls, indexers, proposals, notes, and render support.

Main Gap

The largest immediate gap is the professional editing substrate: enough media, assembly, compositing, tracking/masks, color, audio, graphics, and delivery components for a later decision layer to orchestrate reliably.

Product North Star

Goal: build an agent editor that can make edits with the judgment, craft, and technical range of a professional video editor for users who are not professional editors.

Not the goal: clone DaVinci Resolve, Premiere, or Final Cut as interfaces. Those tools are references for professional task coverage and decision quality.

Sequencing principle: build the professional editing pipeline components first. The autonomous decision layer becomes much more reliable when the agent has the same substrate a professional editor depends on.

What the Agent Must Do

  • Understand the requested outcome, audience, platform, style, and constraints.
  • Inspect source footage and index evidence before making decisions.
  • Choose story, rhythm, continuity, visual, audio, color, graphics, and delivery operations autonomously.
  • Persist intent and evidence so users and future agents understand why edits were made.
  • Show reviewable proposals without requiring the user to know editing terminology.

How to Use Resolve/Premiere Research

  • Use them to discover the complete capability surface of professional editing.
  • Map the pipeline professional editors move through before deciding which agent logic to automate.
  • Translate visible editor controls into agent tools, evidence models, and decision policies.
  • Prefer Montage-native workflows when the agent can remove manual burden.
  • Measure success by whether a professional editor would recognize the result as intentional, clean, paced, watchable, and deliverable.

Current Montage Strengths

Agent-Native Editing Core

crates/core/src/tools/apply_edl.rs and crates/core/src/edl/op.rs give Montage a structured, approval-gated mutation path. The EDL operation set is broad: trim, split, insert, move, b-roll, PiP, transitions, cut intent, audio, color, LUT, title, caption, output format, loudness, and package metadata.

Intent Preservation

crates/proto/src/montage_meta.rs already stores semantic hard-cut metadata and split-edit metadata. The desktop timeline and inspector expose cut badges plus J/L offset markers.

Evidence Architecture

The default indexers cover audio energy, scene detection, whisper, topics, editorial moments, CLIP, face, shot, gaze, frame quality, and color analysis. The shot indexer already emits edit-aware signals such as motion, dominant direction, eye trace, action score, occlusion score, and match candidates.

Desktop Review Surface

The app has chat, transcript, edit history, media preview, timeline, inspector, notes, proposal actions, permission modes, job status, import, indexing, and export. That is the right shape for agent collaboration.

Gap Map

1. Media Pool, Bins, and Asset Metadata

High

Resolve starts with organized media. Montage imports, proxies, and indexes assets, but lacks first-class bins, smart collections, editable asset tags, source review status, relink/offline state, and agent-queryable selection sets.

Direction: add an asset catalog layer separate from timeline clips.

2. Workflow Modes or Task Lenses

Medium

Resolve's pages make task context explicit. Montage uses panes, which is flexible but less task-directed.

Direction: add lightweight task lenses for media, assembly, VFX, color, audio, and delivery without copying Resolve chrome.

3. General Keyframes

High

Resolve animates inspector properties with keyframes and splines. Montage has title animation presets and static effect params, but no general animated parameter model.

Direction: introduce a parameter animation schema for title transform, opacity, scale, position, volume, and later arbitrary effects.

4. Node Compositing Model

High

Fusion work is a DAG of media, merge, mask, transform, tracker, and output nodes. Montage's graph-native effects are still flat clip/timeline effects.

Direction: start with a small serializable composition graph for overlays and tracked inserts.

5. Tracking, Masks, and Mattes

High

Resolve tutorials repeatedly use point, planar, surface, and 3D tracking plus masks/mattes. Montage has motion and composition evidence, but not reusable track paths or mask shapes.

Direction: add tracker and mask sidecar contracts before UI.

6. Color Match Workflow

Medium High

Montage has color analysis, sliders, and LUTs. Resolve color work also expects scopes, reference stills, shot groups, grade consistency, and before/after review.

Direction: turn color correction into a review workflow with references and contact sheets.

7. Mixer-Depth Audio

Medium

Montage has good audio primitives: fades, gain, ducking, FX, loudness, and waveforms. It lacks a mixer-style surface with meters, buses, automation lanes, and audio review packages.

Direction: expose dialogue/music/SFX roles and mixer task lens on top of existing primitives.

8. Delivery Profiles and Render Queue

Medium

Resolve treats delivery as a workspace. Montage has export and render jobs but lacks named profiles, batch queue, platform validation, preflight, and package manifests.

Direction: add data-driven delivery profiles and preflight checks.

9. Fast Editing Ergonomics

Medium

The EDL can represent many edits, and the desktop supports trim/move proposals. It still needs high-frequency direct tools: ripple, roll, slip, slide, marker UI, keyboard commands, and track targeting.

Direction: keep EDL canonical while improving direct manipulation and command palette flows.

10. Reusable Motion Graphics

Medium High

Montage supports titles and broadcast overlays, but Resolve workflows expect editable title templates, text animation, write-on effects, textures, particles, and 3D-like generators.

Direction: start with reusable lower-third/title templates and parameterized text animations.

Inspector Animation Generalize keyframes and animated inspector properties. Keyframes; reusable motion graphics.

Finishing Workflows Turn color, audio, and delivery into review workflows with preflight reports. Color match; mixer-depth audio; delivery profiles.
Autonomous Decision Layer After the core substrate exists, teach the agent to choose and sequence professional operations across the whole pipeline. Brief understanding, footage triage, multi-pass editing, taste profiles, evidence-backed reasoning, and learning from approvals.

  • Should Montage expose Resolve-like workflow modes, or keep panes and add agent task lenses?
  • Do we want a full node graph eventually, or a smaller composition graph focused on tracked overlays, titles, masks, and reusable effects?
