What Montage Does Today

Layer Current behavior Effect on clip count
Editorial moments Claude-backed indexer asks for 2-6 useful beats per topic: hooks, stories, punchlines, setups, questions, answers, CTAs, emotional peaks, dead-air, tangents, explanations. Good for quality, but recall depends on topic segmentation and can miss variant windows.
Fused understanding Builds fused moments from editorial-moments plus transcript, scene, topic, and audio evidence. Only as broad as the input moments; it does not independently sweep every possible 45-90s window.
Clip candidates Creates one expanded candidate per fused moment when average score is at least 0.45. Produces reviewable candidates, not Opus-style variants.
Short-form review Ranks candidates by hook strength, standalone clarity, emotional intensity, educational value, completeness, visual potential, trend relevance, retention prediction, and penalties. Default truncates to 15; tool API can return up to 50.
Viral extractor skill Script example uses --limit 8 and --max-overlap-ratio 0.5. Explicitly suppresses the kind of overlapping variants Opus exposes.
Production package Returns draft EDL, captions, B-roll plan, vertical layout, platform variants, and render/export workflow. Stronger than Opus for controlled production once the candidate is chosen.

Gap Summary

Recall

Montage is too conservative by default. It optimizes for review-ready clips, while Opus gives a large opportunity inventory.

Variants

Opus creates alternate lengths and titles for the same zone. Montage generally creates one candidate from one moment.

Scores

Opus exposes creator-friendly Hook/Flow/Value/Trend grades. Montage has richer internals but does not present them in that simple decision language.

Quality Control

Montage has stronger downstream controls: EDL, visual support, captions, layout, render, and verification receipts.

Recommended Product Change

Add a separate Clip Harvest mode before the existing review-ready short-form planner.

Mode Purpose Defaults
harvest Find everything that could become a post, including variants and borderline clips. Return up to 50, allow overlap, group by source cluster, label variants.
review Pick the best candidates to actually edit/export. Return 10-15, suppress overlap, require hook/context/payoff clarity.
publish Turn selected candidates into finished shorts. Apply EDL, reframe, captions, B-roll, render, verify.

Implementation Priority

  1. Add discovery_mode to plan_short_form_review: harvestreviewpublish.
  2. In harvest mode, merge clip_candidates, moments, transcript topic windows, and sliding phrase windows instead of returning early from the first non-empty source.
  3. Add cluster metadata: cluster_id, variant_kind, overlap_ratio, primary_candidate_id.
  4. Expose Opus-like display grades mapped from current internals: Hook, Flow, Value, Trend, Technical.
  5. Update the viral-clip-extractor workflow to run harvest first, then review the top clusters, then publish selected clips.
