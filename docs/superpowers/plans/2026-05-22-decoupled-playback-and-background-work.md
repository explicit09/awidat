# Decoupled playback + visible background work

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pivot the timeline preview from "refuses to play without a proxy" to "always plays whatever is available," with a persistent footer status bar that exposes background transcode work, a color-coded timeline ruler that signals cache state, smart-prioritized transcoding around the playhead, and a real Media-Offline UX for missing source files.

**Architecture:** Five tiers that build on each other.

1. **Tier 1 — Decouple playback from proxy.** Add a `playable_path` (source-or-proxy) on every timeline clip. Stop filtering clips that lack a proxy. The transcoder becomes a quiet quality-upgrade pass, not a correctness requirement. This retires the entire "Generating preview…" bug class.
2. **Tier 2 — Persistent footer status bar.** Surface every active `JobEmitter` job in a footer pill with click-to-expand details. Failure is visible instead of silent.
3. **Tier 3 — Color-coded timeline ruler.** Ruler segments tint green / amber / red based on per-clip playable kind so the user sees what's smooth, what's playing from source, and what's broken.
4. **Tier 4 — Smart transcode prioritization.** When the project-load backfill or insert-time kickoff fires, transcode clips near the playhead first, then the rest of the cut, then the rest of `raw/`.
5. **Tier 5 — Media-Offline overlay + relink.** When a source asset is genuinely missing on disk, show a red overlay on the affected clip with a "Locate…" file picker that updates the OTIO `target_url`.

**Tech Stack:** Rust (awidat-desktop tauri commands, awidat-desktop-protocol, awidat-core), TypeScript (React frontend), ts-rs for generated protocol types, tokio for async background work, Vite for HMR.

```rust
//! Resolves what file the player should hand to <video src> for a
//! clip on the timeline. Falls back through (proxy → source → none)
//! so the timeline preview can play the original asset while a proxy
//! is still transcoding, instead of staring at a "Generating preview…"
//! placeholder.

use std::path::{Path, PathBuf};

use awidat_desktop_protocol::PlayableKind;

/// What the frontend will play for a given asset id.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Playable {
    pub path: Option<PathBuf>,
    pub kind: PlayableKind,
}

/// Resolve the play URL for `<project>/<asset_id>`. Prefers the 1080p
/// proxy when it exists, falls back to the source asset, returns
/// `Missing` only when the source itself is gone.
pub fn playable_for_asset_id(project_root: &Path, asset_id: &str) -> Playable {
    let abs = project_root.join(asset_id);
    if !abs.is_file() {
        return Playable {
            path: None,
            kind: PlayableKind::Missing,
        };
    }
    if let Some(proxy) = crate::commands::media::proxy_path_for_asset_id(project_root, asset_id) {
        return Playable {
            path: Some(PathBuf::from(proxy)),
            kind: PlayableKind::Proxy,
        };
    }
    Playable {
        path: Some(abs),
        kind: PlayableKind::Source,
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use crate::commands::media::proxy_path_for;

    #[test]
    fn returns_missing_when_source_absent() {
        let tmp = tempfile::tempdir().unwrap();
        let got = playable_for_asset_id(tmp.path(), "raw/nope.mov");
        assert_eq!(got.kind, PlayableKind::Missing);
        assert!(got.path.is_none());
    }

    #[test]
    fn returns_source_when_source_present_but_no_proxy() {
        let tmp = tempfile::tempdir().unwrap();
        let raw = tmp.path().join("raw");
        std::fs::create_dir_all(&raw).unwrap();
        let asset = raw.join("clip.mov");
        std::fs::write(&asset, b"src").unwrap();
        let got = playable_for_asset_id(tmp.path(), "raw/clip.mov");
        assert_eq!(got.kind, PlayableKind::Source);
        assert_eq!(got.path.as_ref().unwrap(), &asset);
    }

    #[test]
    fn returns_proxy_when_proxy_exists() {
        let tmp = tempfile::tempdir().unwrap();

import { useState } from "react";
import { JobsPanel } from "./JobsPanel";

export type ActiveJobLike = {
  id: string;
  kind: string;
  percent: number;
  status: string;
};

type Props = {
  jobs: ActiveJobLike[];
  totalPercent: number | null;
};

export function JobsStatusBar({ jobs, totalPercent }: Props) {
  const [open, setOpen] = useState(false);
  if (jobs.length === 0) {
    return <span className="footer-jobs footer-jobs-idle">Idle</span>;
  }
  const grouped = groupByKind(jobs);
  const parts = grouped.map((g) => `${g.count} ${kindLabel(g.kind)}`);
  const summary = parts.join(", ");
  const pct = totalPercent ?? aggregatePercent(jobs);
  return (
    <div className="footer-jobs">
      <button
        type="button"
        className="footer-jobs-pill"
        aria-expanded={open}
        onClick={() => setOpen((o) => !o)}
      >
        <span className="footer-jobs-spinner" aria-hidden />
        <span>{summary}</span>
        {pct !== null && <span className="footer-jobs-percent">{Math.round(pct)}%</span>}
      </button>
      {open && <JobsPanel jobs={jobs} onClose={() => setOpen(false)} />}
    </div>
  );
}

function groupByKind(jobs: ActiveJobLike[]): { kind: string; count: number }[] {
  const counts = new Map<string, number>();
  for (const job of jobs) counts.set(job.kind, (counts.get(job.kind) ?? 0) + 1);
  return Array.from(counts, ([kind, count]) => ({ kind, count }));
}

function kindLabel(kind: string): string {
  switch (kind) {
    case "transcode": return "transcoding";
    case "indexing":  return "indexing";
    case "thumbnails": return "thumbnailing";
    case "waveform":  return "waveform";
    case "render":    return "rendering";
    default:          return kind;
  }
}

function aggregatePercent(jobs: ActiveJobLike[]): number | null {
  if (jobs.length === 0) return null;
  const sum = jobs.reduce((s, j) => s + (Number.isFinite(j.percent) ? j.percent : 0), 0);
  return sum / jobs.length;
}

import type { PlayableKind } from "../protocol";

export type CacheStripInput = {
  startS: number;
  endS: number;
  kind: PlayableKind;
};

export function cacheStripSegments(clips: CacheStripInput[]): CacheStripInput[] {
  const out: CacheStripInput[] = [];
  for (const clip of clips) {
    const prev = out[out.length - 1];
    if (prev && prev.kind === clip.kind && Math.abs(prev.endS - clip.startS) < 0.001) {
      prev.endS = clip.endS;
    } else {
      out.push({ ...clip });
    }
  }
  return out;
}

/// Re-order a (id, timeline_start_s, timeline_end_s) asset list so
/// transcoding starts with whatever the user is most likely to play
/// next. Assets the cursor sits on come first, then nearest neighbors,
/// then the long-tail off-screen assets.
pub fn prioritize_for_cursor(
    assets: &[(String, f64, f64)],
    cursor_s: f64,
) -> Vec<String> {
    let mut scored: Vec<(f64, &String)> = assets
        .iter()
        .map(|(id, start, end)| {
            let distance = if cursor_s >= *start && cursor_s <= *end {
                0.0
            } else if cursor_s < *start {
                start - cursor_s
            } else {
                cursor_s - end
            };
            (distance, id)
        })
        .collect();
    scored.sort_by(|a, b| a.0.partial_cmp(&b.0).unwrap_or(std::cmp::Ordering::Equal));
    scored.into_iter().map(|(_, id)| id.clone()).collect()
}
```

pub async fn relink_missing_asset(
    app: AppHandle,
    state: State<'_, AwidatState>,
    old_asset_id: String,
    new_asset_id: String,
) -> Result<(), String> {
    let project_root = state
        .project_root
        .lock()
        .await
        .clone()
        .ok_or_else(|| "no project loaded".to_string())?;
    let otio_path = project_root.join("project.otio.json");
    let bytes = tokio::fs::read(&otio_path)
        .await
        .map_err(|e| format!("read otio: {e}"))?;
    let mut json: serde_json::Value =
        serde_json::from_slice(&bytes).map_err(|e| format!("parse otio: {e}"))?;
    let mut changed = 0_usize;
    walk_external_refs(&mut json, &old_asset_id, &new_asset_id, &mut changed);
    if changed == 0 {
        return Err(format!("no ExternalReference matched {old_asset_id}"));
    }
    tokio::fs::write(&otio_path, serde_json::to_vec_pretty(&json).unwrap())
        .await
        .map_err(|e| format!("write otio: {e}"))?;
    crate::events::emit_timeline_changed(&app, &project_root);
    Ok(())
}

fn walk_external_refs(
    value: &mut serde_json::Value,
    old: &str,
    new: &str,
    changed: &mut usize,
) {
    match value {
        serde_json::Value::Object(map) => {
            if map.get("OTIO_SCHEMA")
                .and_then(|s| s.as_str())
                .is_some_and(|s| s.starts_with("ExternalReference"))
                && map.get("target_url").and_then(|t| t.as_str()) == Some(old)
            {
                map.insert(
                    "target_url".into(),
                    serde_json::Value::String(new.into()),
                );
                *changed += 1;
            }
            for child in map.values_mut() {
                walk_external_refs(child, old, new, changed);
            }
        }
        serde_json::Value::Array(arr) => {
            for child in arr.iter_mut() {
                walk_external_refs(child, old, new, changed);
            }
        }
        _ => {}
    }
}

import { invoke } from "@tauri-apps/api/core";
import { open as openDialog } from "@tauri-apps/plugin-dialog";
import { useState } from "react";

type Props = {
  assetId: string;
  onRelinked: () => void;
};

export function MediaOfflineOverlay({ assetId, onRelinked }: Props) {
  const [busy, setBusy] = useState(false);
  const [err, setErr] = useState<string | null>(null);
  async function locate() {
    setBusy(true);
    setErr(null);
    try {
      const picked = await openDialog({
        directory: false,
        multiple: false,
        title: `Locate ${assetId}`,
      });
      if (typeof picked !== "string") {
        setBusy(false);
        return;
      }
      // The picked path may be absolute; the backend rewrites it to
      // a project-relative id when applying.
      await invoke("relink_missing_asset", {
        oldAssetId: assetId,
        newAssetId: picked,
      });
      onRelinked();
    } catch (e) {
      setErr(String(e));
    } finally {
      setBusy(false);
    }
  }
  return (
    <div className="media-offline-overlay">
      <span className="media-offline-badge">Media offline</span>
      <code>{assetId}</code>
      <button type="button" onClick={locate} disabled={busy}>
        {busy ? "Locating…" : "Locate…"}
      </button>
      {err && <p className="media-offline-error">{err}</p>}
    </div>
  );
}
