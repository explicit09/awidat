Strict Consumer Installer Plan

Implementation is split into locally testable release helpers, strict Apple signing/notarization workflow, docs, and final verification.

1. Red Tests

Add shell tests before helper scripts exist.

2. Helper Scripts

Validate env, sidecars, checksums.

3. Apple Scripts

Import Developer ID cert, notarize, staple.

4. Release Workflow

Build both macOS DMGs and publish on v* tags.

5. Docs

Document required secrets and local rehearsal command.

6. Verification

Local checks pass; GitHub run proves Apple credentials.
