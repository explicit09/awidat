Provider Key Vault Implementation Plan

Build the approved local-first BYO key path: one keychain-backed vault, Advanced settings UI, explicit legacy import, and friendly missing-key prompts.

1. Vault Model

Add versioned JSON vault types and env-first pure lookup in crates/secrets.

2. Vault Storage

Persist all provider keys in one montage / secrets_vault Keychain item.

3. Runtime Lookup

Make generic lookup use env vars, then the cached vault, without legacy probing.

4. Tauri Commands

Add list, save, remove, test, and explicit import commands for provider keys.

5. Advanced UI

Add Settings -> Advanced -> Provider Keys with add, replace, and remove actions.

6. Friendly Prompts

Replace raw env-var errors with feature-specific setup copy.

The Markdown plan contains the exact file paths, test commands, and step-by-step TDD checkpoints.
