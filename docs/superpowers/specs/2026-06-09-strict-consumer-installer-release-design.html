Strict Consumer Installer Release

Build signed and notarized macOS DMG installers from GitHub Actions. The release fails if Apple credentials, sidecars, signing, notarization, or artifact checks are not correct.

Ships Now

  • Apple Silicon DMG
  • Intel macOS DMG
  • Real codex and yt-dlp sidecars
  • Checksums and GitHub Release upload

Hard Gates

  • Apple secrets present
  • Developer ID cert imported
  • DMG signed, notarized, stapled
  • No CI sidecar stubs

Later

  • Homebrew formula
  • Linux and Windows packages
  • Updater feed/signatures
  • Installed-app smoke tests

Release Flow

checkout
install toolchains
fetch sidecars
verify no stubs
import cert
tauri build dmg
notarize + staple
checksums
GitHub Release
