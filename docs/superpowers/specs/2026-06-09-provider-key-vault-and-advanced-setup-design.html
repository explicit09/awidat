Provider Key Vault and Advanced Setup

Montage stays local-first: no managed credits yet. Provider keys remain bring-your-own, but move into one Advanced settings flow backed by a single secure vault.

Product Direction

  • No hosted billing or credits in this phase.
  • Normal users avoid provider setup until a feature needs it.
  • Power users can add their own keys in Advanced settings.

Vault Model

  • One Keychain item: montage / secrets_vault.
  • Versioned JSON stores all provider secrets.
  • Runtime reads once and serves lookups from memory.

User Setup

  • Settings -> Advanced -> Provider Keys.
  • Each provider has Add, Replace, Test, Remove.
  • Feature prompts use friendly text, not env-var names.

Implementation Rollout

1Keep debug startup prefetch off.
2Add vault read/write API.
3Add provider status commands.
4Build Advanced settings UI.
5Route missing-key prompts.
6Add explicit legacy import.

Legacy per-key entries should not be probed at launch. Importing them is an explicit Settings action because macOS may prompt once per old key.
