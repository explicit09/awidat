fixed + measured

Project-switch decoder retention

The initial cache fix bounded app-owned transcript/LUT/filmstrip/waveform state, but a 16-open native control still reached 1,143.2 MiB; the GPU process alone reached 622.3 MiB. Explicit unload was insufficient because WebKit retained allocations for newly created media elements.

The final implementation keeps one double-buffered preview host mounted across Project Manager transitions, unloads it on each root change, and reuses the same two media elements. Unity-gain playback also avoids allocating WebAudio.
