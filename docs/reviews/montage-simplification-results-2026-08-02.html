Montage · simplification results

Seven cuts. Runtime-tested.

Dormant facades, duplicate subsystems, dead adapters, and every production-unreachable frontend module are gone. The retained editor was then exercised against real 34-minute and 6-minute projects; dogfood-found playback and subprocess-lifecycle failures were fixed instead of hidden behind green builds.

1 · Development lanes

Repaired first-party Make targets, removed an empty feature, removed ten unused direct dependencies, and reduced dormant core orchestration.

2 · Publishing

Deleted the duplicate desktop OAuth, keychain, provider, storage, upload-queue, and platform stack. Publishing now converges on the existing social server.

3 · Professional facade

Removed the unused workflow/readiness facade and its uncalled commands. A live audio-finishing helper discovered by compile evidence was retained in a focused module.

4 · Preview cache

Deleted the second desktop preview cache and its uncalled endpoints. The active persisted, resumable, ffmpeg-backed core lifecycle remains authoritative.

5 · Desktop adapters

Removed unused dismissal/review modules and uncalled raw motion/social wrappers while preserving Notes dismissal persistence, MCP review packaging, motion-region workflows, and server-backed social commands.

6 · Runtime edge cases

Made the Codex sidecar build honor the configured target directory and fail honestly, canonicalized /tmp media paths, and made video-only waveform extraction return an empty result instead of ffmpeg error 234.

7 · Frontend reachability

Deleted eight unmounted surfaces, then removed the remaining 17 modules unreachable from all six shipped entries, their dead-only tests, and the unused Radix Dialog dependency. The resolver-backed graph is now 309/309 reachable.

Dogfood hardening

Space-to-pause now reads live playback state instead of a stale first-render closure. Desktop jobs share one cancellation root and registry, with cleanup on both Tauri exit signals. Loaded chat history no longer refetches merely because its menu opens, and proposal handles now remain draggable above review overlays with hundredth-second payload precision.

Intentionally deferred

Commands with dynamic or internal call possibilities were not removed on name-search evidence alone. Frontend-visible history rename/delete stubs were also left intact because deleting them would change user-visible behavior and overlap unrelated local UI work.

Automated review

The pushed simplification head passed format, security, Linux Rust, macOS Rust, and desktop frontend CI. Later local review bundles were refused by the secret scanner because deleted context contains ordinary identifiers such as CancellationToken and loadToken; production code was not rewritten to appease the scanner.

Checkout preservation

The original checkout's modified App.css, episode-start tool, secrets library, and untracked target link were not touched. All simplification commits remain isolated in the dedicated worktree.

Known product gaps

Expected failures remain for absent recent-project search/removal affordances, direct split, and immediate undo/redo. Notes is skipped because no mounted Notes product surface exists. The matrix reports a warning rather than a blocker.

Media boundary retained

The external source symlink was deliberately rejected by preview confinement. Dogfood used project-local caches and never weakened the rule that preview media must resolve inside the project's media directories.
