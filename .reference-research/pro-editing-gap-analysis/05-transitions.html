Transitions

Gap analysis - Category 5 - Awidat vs reference NLEs (kdenlive, shotcut, olive, openshot-qt, revideo, opencut).

What this covers

Transition engine, planner, type catalog, render path, J/L cut grammar, speed-ramp transitions. Excludes the general animation kernel (Cat 4), pure compositing/masking (Cat 7), and timeline-wide speed remap (Cat 8).

  • Planner tools: transition_context, plan_transition, validate_transition_choice
  • Catalog: ~33 BUILTIN_TRANSITIONS across 14 families, FFmpeg xfade + WGSL backends
  • Composition primitives (14 ops + Atomic) with multi-keyframe param curves
  • J/L cuts as first-class EDL ops with learned timing guidance

Status snapshot

Agent planner
Context packet, recommend, validate. Actively prefers hard cuts; visible transitions only with a named job (hide_motion_jump, beat_hit, soft_time_passage, chapter_reset, visual_match, style_accent).
J / L cut grammar
First-class Set Audio Lead / Set Audio Trail EDL ops, dedicated split-edit-director skill, learned lead_s / trail_s defaults. Ahead of every reference editor surveyed.
Motion-aware validation
validate_transition_choice compares declared motion_alignment against measured per-side dominant_direction and returns wrong_direction / acceptable / no_signal. No reference NLE has this loop.
Transition catalog breadth
~33 curated ids across dissolves, fades, wipes, slides, motion blur, iris, zoom, occlusion, luma mask, light leak, swirl. Openshot ships 400+ wipes - the LumaMask primitive's promised texture field is not wired yet.
Glitch family
Only awidat.pixelize (FFmpeg xfade) and the ChromaticSplit primitive. No scan-lines, RGB-shift named id, datamosh, or signal-loss grammar.
Film burns
No awidat.film_burn id. Closest is awidat.light_leak; no warm-grain composite recipe combining leak + grain + cross.
Speed-ramp transitions
TransitionPrimitiveOp::TimeRemap { speed } plus awidat.ramp_in_beat and awidat.ramp_out_chapter now capture speed-ramp intent. plan_transition can pair beat_hit with a ramp; render currently uses the paired visual fallback until transition-local retime execution lands.
Backend mixing
Mixing FFmpeg xfade and GPU transitions inside one render is rejected at raw_stream_render.rs:45. GPU-only entries force a whole-project GPU render.
Per-transition audio policy
TransitionAudioPolicy::Crossfade | Cut exists on every entry. Whether Cut renders a true hard audio cut or just no fade curve is unverified.

Reference signals

kdenlive

15 MLT transition XMLs + 46 frei0r blends; data/transitions/luma.xml exposes softness/invert/reverse/alpha_over as declarative params. Split edits are manual multi-track trims.

shotcut

Single LumaMixTransition widget binds the MLT luma transition with a wipe-texture picker and softness slider. No dedicated J/L cut primitive.

olive

TransitionBlock node owns one in/out offset, ShaderJobEvent + SampleJobEvent; concrete subclasses ship a tiny C++ class plus one GLSL .frag (e.g. crossdissolve.frag). Single node handles video + audio.

openshot-qt

7 core wipes plus ~405 extra luma-mask wipes (ripple, twirl, spiral, distortion, ...). All are softness + reverse around a luma image - same model the Awidat LumaMask primitive could ingest.

revideo

Transitions are render callbacks (useTransition manipulates the outgoing/incoming scene's Context2D). Fade / slide / zoomIn / zoomOut only. No semantic intent layer.

opencut

No transition primitive in the timeline data model. Confirms a modern web NLE can skip transitions entirely.

Top gaps

Speed-ramp render execution remains med

The semantic and planner gap is closed with TransitionPrimitiveOp::TimeRemap { speed }, awidat.ramp_in_beat, and awidat.ramp_out_chapter. Render backends still use the paired visual primitive as fallback until transition-local retime lowering is implemented.

Glitch family is one entry deep med

awidat.pixelize (FFmpeg xfade) is the only family: "glitch" member. Promote ChromaticSplit to a named id; add ScanLines, Datamosh, SignalLoss primitives + ids. Update style_accent path so glitch is a real candidate.

Film burns missing med

No awidat.film_burn id. Compose LightLeak + grain + cross-dissolve into a named recipe so the planner can reach for the warm-organic family beyond just light_leak.

Image-based luma masks not wired med

TransitionPrimitive::LumaMask documents "Future image-based masks (Kdenlive ports) extend the same primitive with a texture asset reference." Adding that field opens the door to openshot's 400+ wipe library without bloating the named-id catalog.

Cannot mix xfade and GPU transitions in one render med

raw_stream_render.rs:45 hard-rejects mixed-backend timelines. Route each boundary through its declared backend and re-concat so a project can use the broad xfade set on most cuts and reserve GPU shaders for the few that need them.

Suggested next moves

  1. Lower transition-local TimeRemap speed curves in render so awidat.ramp_in_beat and awidat.ramp_out_chapter execute the retime, not only their paired visual fallback.
  2. Add a texture: Option<AssetRef> field on LumaMask; ingest a small openshot-port wipe library to validate the path.
  3. Add ScanLines, Datamosh, SignalLoss primitives and 2-3 named glitch ids; expose family: "glitch" in style_accent routing.
  4. Compose a named awidat.film_burn (and a short variant) from light_leak + grain + cross-dissolve.
  5. Lift the mixed-backend render block so a single timeline can use both FFmpeg xfade boundaries and WGSL-shader boundaries.
