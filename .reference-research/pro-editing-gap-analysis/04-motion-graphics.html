Motion Graphics & Animation

Awidat category 4 of 13 · planner → proto → render → preview chain for making static shots feel dynamic.

What this covers

Keyframe data model, easing/bezier/spring curves, motion paths, transform parameters (position, scale, rotation, opacity, blur), tracking-driven motion, and animated graphic primitives (titles, lower-thirds, callouts, logo reveals) that an agent can plan, persist, and deterministically render. Transitions are owned by Category 5, pure VFX by Category 7, typography by Category 9.

Reference signals

opencut closest peer

Scalar/discrete channels with leftHandle/rightHandle {dt,dv}, segmentToNext (step/linear/bezier), tangentMode (auto/aligned/broken/flat), per-channel before/after extrapolation. Unified namespace: transform.*, opacity, color, background.*, effects.<id>.params.<p>.

apps/web/src/animation/{types.ts, graph-channels.ts, effect-param-channel.ts}

revideo code-first

Generator-driven scenes: tween(), spring() with mass/stiffness/damping/initialVelocity, 28+ named easings (1:1 with Awidat's catalog). Lower-thirds are composed Layout/Txt/Img components, not a fixed template list. No FFmpeg expression lowering — playback in browser/headless renderer.

packages/core/src/tweening/{tween.ts, spring.ts, timingFunctions.ts}, packages/2d/src/lib/components/

hyperframes HTML/GSAP

Parses real GSAP set/to/from/fromTo calls. SUPPORTED_EASES (power1-4.{in,out,inOut}, back, elastic, bounce, expo) is a direct subset of Awidat's easing set. Renders motion graphics through a headless DOM/GSAP engine.

packages/core/src/parsers/gsapParser.ts, packages/engine/src/

twick declarative

Tiny ElementAnimation add-on: name, interval, duration, intensity, animate (enter/exit/both), mode, direction. Renderer interprets the named animation; no keyframes/curves. Weaker than Awidat for low-level control.

packages/timeline/src/core/addOns/animation.ts

openshot-qt preset library

~30 Animate.css-derived presets (bounce, flash, pulse, rubberBand, shakeX/Y, swing, tada, fadeIn*, slideIn*, zoomIn*) stored as (frame, value, easing_name) tuples. KEYFRAME_EASING is CSS cubic-bezier(x1,y1,x2,y2) mapped to libopenshot handles. Easy to mine for Awidat emphasis presets.

src/animation_presets.py

olive & kdenlive node graph / MLT

Olive NodeKeyframe: Linear / Hold / Bezier with QPointF in/out handles — no Spring/Elastic interpolation kinds. Kdenlive stores std::map<GenTime, pair<KeyframeType, QVariant>> derived from MLT enums. Titler is a separate QGraphicsScene authoring subsystem (src/titler/).

olive/app/node/keyframe.h, kdenlive/src/assets/keyframes/model/keyframemodel.hpp, kdenlive/src/titler/

Suggested next moves

  1. Keep expanding the effect-parameter registry. effects.<id>.params.<p> namespacing now exists for executable in-tree blur, shake, and warp params; new effects should declare animatable params through the same registry.
  2. Bezier motion paths. Add optional in/out handles per MotionPathPoint and "orient along path"; reuse the existing scalar bezier evaluator/sampler.
  3. TrackerAttachment animation target. New AnimationTarget variant that resolves to per-frame x/y from a tracking package, routed through overlay x/y lowering.
  4. Planner-visible time remap. Connect plan_emphasis to the existing clip-local retime support and Cat 5 TimeRemap transition primitive.
  5. Per-character/word title stagger. Extend TitleAnimation with Stagger {unit, delay_s, easing}; lower in progressive_titles.
  6. Generalize render-gpu. Add a transform/blur/opacity pass driven by RenderParameterAnimation so preview is shader-driven and matches export.
  7. Mine openshot-qt presets. Port a dozen Animate.css presets into plan_emphasis's style palette.
